# Credits and provenance

## Original implementation

PictoRust is based on **PictoChat Online / ayunpictojava**, the browser recreation
of Nintendo DS / DSi PictoChat by **[ayunami2000](https://github.com/ayunami2000)**.

- Original project: https://github.com/ayunami2000/ayunpictojava
- Original Java server, browser interaction model, PIXI-based composition,
  visual assets, Nintendo DS-inspired graphics, layout and bundled pixel font
  originate from that upstream project.
- The Git history and the upstream source remain part of this fork. Do not
  remove upstream notices, authorship, or asset attribution.
- The independent Nintendo/Nintendo DS/PictoChat names and associated imagery
  belong to their respective rights holders. This fork is not affiliated with
  or endorsed by Nintendo or the original upstream author.

## PictoRust modernization

The PictoRust fork adds an experimental Rust in-memory WebSocket relay,
client-side crypto research, Unicode work, original-sprite interface refinements,
browser regression tests, print/PDF rendering and documentation.

Fork development: https://github.com/MikailGtheG/pictorust
